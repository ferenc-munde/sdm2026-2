Documentation for the platform, next to [../ARCHITECTURE.md](../ARCHITECTURE.md) and [../CLAUDE.md](../CLAUDE.md).

- `RAILWAY_SETUP.md`: how the Railway project `sdm2026-2` is set up and checked, and how a release is checked by hand.
- `design-docs/`: one document per design decision (for example the room base).
